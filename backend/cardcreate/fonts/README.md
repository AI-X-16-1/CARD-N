# cardcreate/fonts/

- `NotoSansKR-Variable.ttf` — Noto Sans KR, from the
  [google/fonts](https://github.com/google/fonts/blob/main/ofl/notosanskr)
  repository (SIL Open Font License 1.1). Used by `cardcreate/overlay.py`
  because Pillow's built-in default font has no Hangul glyphs.

**Note for the PR review**: committed directly (~10MB) for simplicity while
this module is a draft - worth reconsidering before merging, same as the
